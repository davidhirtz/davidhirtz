### Hi, I'm David

Freelance software engineer and technical consultant based in Munich, Germany. For more than two decades, I have been turning complex requirements into custom web software for international agencies, brands and universities, from architecture to deployment. More than 80 websites and applications currently run on systems I have built.

Most of my client work lives in private repositories. What you'll find here are the open-source frameworks behind it.

---

### What I work on

- **Custom web applications**: requirements analysis, data modelling, architecture and long-term maintainability
- **Shopify development**: custom storefronts, theme and app development, and syncing products and data between Shopify and custom backends via the GraphQL API
- **Integrations**: connecting custom software to the services businesses already rely on, from authentication (SAML/Shibboleth SSO, LDAP) and infrastructure (Cloudflare, AWS) to marketing and CRM (Brevo, Mailchimp, Zoho), media (Cloudinary), maps and geodata (Google Maps, GeoIP) and commerce (Shopify, Amazon PA-API), plus many more REST and GraphQL APIs
- **Security and quality**: RBAC, security audits, automated testing, static analysis and CI/CD
- **AI-assisted engineering**: integrating AI into development workflows and products while keeping humans in charge of architecture and review

### Open source

A family of 15 Composer packages, developed and released together in one monorepo, with about 170,000 lines of PHP and 450 test classes:

| Package | What it does |
|---|---|
| [yii2-skeleton](https://github.com/davidhirtz/yii2-skeleton) | Application core, database layer, RBAC, admin module, widget system |
| [yii2-cms](https://github.com/davidhirtz/yii2-cms) | Entries, sections, categories and content blocks |
| [yii2-media](https://github.com/davidhirtz/yii2-media) | File management, image processing and transformations |
| [yii2-tenant](https://github.com/davidhirtz/yii2-tenant) | Multi-tenancy across domains |
| [yii2-shopify](https://github.com/davidhirtz/yii2-shopify) | Shopify GraphQL Admin API sync |
| [yii2-location](https://github.com/davidhirtz/yii2-location) | Locations, tags and Google Maps integration |
| [yii2-vite](https://github.com/davidhirtz/yii2-vite) | Vite manifest and dev server integration |
